# N-Ways Addressing for Cabo Verde: what you need to install.
#
# Python 3.9 or later. The reference engine and its tests
# (engine/reference/cv_engine.py, plate_names.py, test_cv.py) and every tool
# in tools/ use only Python's standard library: there is no Python package to
# install, so `pip install -r requirements.txt` installs nothing and that's
# expected.
#
# Only to rebuild the data from scratch (tools/building_stats.py,
# tools/issue_registry.py), not to run the engine or use the codes:
#   - the DuckDB command-line tool, 1.1 or later, on PATH as `duckdb`
#     (https://duckdb.org/docs/installation; macOS: brew install duckdb);
#     the tools set its memory limit to 3 GB;
#   - read access to an N-Ways database (NWAYS_DB) and data folder (--root);
#     outside N-Ways, use the published data in registry/ and engine/data/
#     instead.
